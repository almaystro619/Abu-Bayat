# أبو بيان الشماخي — منصة تعليمية عربية

## التشغيل محلياً
1. ثبّت Node.js إصدار 18 أو أحدث.
2. فك ضغط المشروع.
3. افتح مجلد المشروع في الطرفية ونفّذ:
   ```bash
   npm install
   cp .env.example .env
   npm start
   ```
4. افتح `http://localhost:3000`.

## تفعيل المعلم الذكي الحقيقي
- أنشئ مفتاح API لدى مزود ذكاء اصطناعي يدعم واجهة OpenAI Chat Completions.
- ضع المفتاح في `AI_API_KEY` داخل `.env`.
- اضبط `AI_BASE_URL` و`AI_MODEL` حسب مزود الخدمة.
- أعد تشغيل الخادم.

**تنبيه:** وضع العرض يعمل دون مفتاح ويعرض رسالة توضيحية؛ لا يدّعي أنه ذكاء اصطناعي حقيقي. استدعاءات الذكاء الاصطناعي تحتاج اتصالاً بالإنترنت وقد تكون لها تكلفة لدى المزود.

## الاستضافة
ارفع المشروع إلى استضافة تدعم Node.js، ثم عيّن أمر التشغيل `npm start` ومتغيرات البيئة. لا ترفع ملف `.env` أو مفتاح API إلى مستودع عام.

## المميزات الحالية
- واجهة عربية متجاوبة للجوال والكمبيوتر.
- مدرس ذكي عبر API (مع وضع تجريبي عند عدم وجود مفتاح).
- تلخيص النصوص عبر API وحفظ الملخصات محلياً.
- بطاقات سؤال/جواب مع وضع قلب البطاقة.
- اختبارات اختيار من متعدد وتصحيح تلقائي.
- قائمة مهام مذاكرة.
- مكتبة مصادر وروابط.
- الوضع الليلي.
- حفظ بيانات الطالب في المتصفح باستخدام localStorage.

## حدود النسخة الأولى
- البيانات محفوظة في المتصفح الحالي ولا تتزامن تلقائياً بين الأجهزة.
- اختيار PDF يظهر للمستخدم، لكن استخراج النص من PDF غير مدمج بعد؛ يمكن لصق النص مباشرة أو استخدام ملف TXT/MD.
- لا يوجد تسجيل دخول أو قاعدة بيانات أو مشاركة عامة في هذه النسخة.
- لا توجد حدود مجانية مضمونة لخدمات الذكاء الاصطناعي الخارجية.
